# 🍔 Estrela do Cardápio - Hambúrguer Healthy

Bem-vindo(a) ao projeto **Hambúrguer Healthy**! Este repositório é uma página promocional interativa criada para apresentar o prato principal do cardápio com uma abordagem criativa, divertida e focada em design web.

---

## 🌟 Sobre o Projeto

Este projeto consiste em uma *landing page* (página de destaque) desenvolvida em arquivo único para demonstrar o uso de **HTML5** e **CSS3** integrados com **ilustrações vetoriais em SVG**. 

A proposta do design é utilizar cores quentes e vibrantes (com fundo laranja) para estimular o apetite, além de utilizar adjetivos bem-humorados no texto publicitário para engajar o cliente de forma descontraída.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do conteúdo da página.
* **CSS3:** Estilização com gradientes, sombras (`box-shadow`), bordas arredondadas e efeitos interativos no botão (`:hover`).
* **SVG (Scalable Vector Graphics):** Ilustração vetorial do hambúrguer diretamente inserida no código HTML, garantindo alta resolução em qualquer tamanho de tela sem perder qualidade.

---

## 📖 Estrutura dos Elementos

O projeto destaca os seguintes elementos do hambúrguer:
* **Pão:** Pão torrado na manteiga com sementes de gergelim.
* **Recheio principal:** Carne de hambúrguer grelhada na Airfryer e fatias de carne de porco.
* **Acompanhamentos:** Queijo mussarela derretido, alface japonesa rasgada manualmente e colherada de maionese especial.
